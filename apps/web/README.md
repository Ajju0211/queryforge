# apps/web - Frontend Web Application

## Overview
This directory contains the Next.js 14+ (App Router) frontend application for the **AI Database Workspace**.

## Technology Stack
- **Framework:** Next.js 14+ (React 18+, TypeScript)
- **Styling:** Tailwind CSS
- **Component Primitives:** shadcn/ui (Radix UI)
- **Data Grid:** TanStack Table v8
- **Charts:** Recharts

## Implementation Scope
- User onboarding and workspace switching
- Database connection management UI (host, port, SSL, credentials)
- Schema viewer and table inclusion/exclusion settings
- Conversational chat interface for natural-language database queries
- Results visualizer (dynamic data table and charts)
- Schema-driven generated admin interface (`/admin/[connId]/[table]`)
